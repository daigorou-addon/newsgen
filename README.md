# NewsGen（ニュース風ジェネレーター）

[日本語](#日本語) | [English](#english)

---

## 日本語

ニュース番組・監視カメラ・デジカメ風の画像を、キャンバス上で自由に編集して作れるWebツールです。インストール不要で、PC・スマホの両方で使えます。

すべての処理はお使いの端末内で行われます。入力内容や画像がどこかに送信されることはありません。

**👉 [今すぐ使う](https://daigorou-addon.github.io/newsgen/)**

### 主な機能

- **テンプレート**: 白紙 / 速報スタンダード / バラエティ見出し / 衝撃テロップ / 二段見出し / 字幕テロップ（縁取り文字） / フォーマルニュース / 監視カメラ風 / デジカメ風
- **要素の追加**: テキスト / 図形・枠 / 画像 / ワイプ（丸・四角）
- **画像**: ボタンから選択、またはPCではキャンバスへのドラッグ＆ドロップで追加できます
- **テキスト**: フォント27種、サイズ、太さ、色、配置、縁取り（字幕風）
- **図形・枠**: 四角 / 角丸 / ピル型 / 丸 / 平行四辺形 / 両斜めカット / リボン（旗型） / 下線バー。色・不透明度・外枠線の設定
- **時刻・天気の表示**: ワンクリックで表示／非表示
- **レイヤー**: 一覧から選択でき、前面へ・背面への並べ替えが可能
- **キャンバスサイズ**: 16:9（1280×720） / 1:1（1080×1080） / 4:5（1080×1350） / 9:16（1080×1920）
- **元に戻す／やり直し**
- **画像保存**: PNGで保存
- **表示テーマ切り替え** と **6言語対応**（日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español）

### 使い方

1. テンプレートを選びます（白紙から始めることもできます）。
2. キャンバス上の要素をクリックして、文字・色・枠の形などを編集します。
3. 「＋ テキスト」「＋ 図形/枠」「＋ 画像」「＋ ワイプ」で要素を追加します。PCでは、画像をキャンバスにドラッグ＆ドロップして追加することもできます。
4. 「画像を保存」でPNG画像として保存します。

## English

NewsGen is a web tool for freely editing and creating news-broadcast, security-camera, and digital-camera style images on a canvas. No installation is required, and it works on both desktop and mobile.

Everything is processed on your own device. Your input and images are never sent anywhere.

**👉 [Try it now](https://daigorou-addon.github.io/newsgen/)**

### Features

- **Templates**: Blank / Breaking Standard / Variety Headline / Impact Caption / Two-line Headline / Subtitle Caption (outlined text) / Formal News / Security Camera / Digital Camera
- **Add elements**: text / shapes and frames / images / insets (circle or square)
- **Images**: add with the button, or on desktop by dragging and dropping onto the canvas
- **Text**: 27 fonts, size, weight, color, alignment, and an outline (subtitle style)
- **Shapes and frames**: rectangle / rounded / pill / circle / parallelogram / double diagonal cut / ribbon (flag) / underline bar. Set color, opacity, and an outer border
- **Time and weather display**: show or hide with one click
- **Layers**: select from the list, and bring forward or send backward
- **Canvas size**: 16:9 (1280×720) / 1:1 (1080×1080) / 4:5 (1080×1350) / 9:16 (1080×1920)
- **Undo / Redo**
- **Save image**: export as PNG
- **Light/dark theme** and **6 languages** (日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español)

### Usage

1. Choose a template (or start from a blank canvas).
2. Click an element on the canvas to edit its text, color, frame shape, and more.
3. Add elements with "+ Text", "+ Shape/Frame", "+ Image", and "+ Inset". On desktop, you can also drag and drop an image onto the canvas.
4. Click "Save Image" to save it as a PNG.
